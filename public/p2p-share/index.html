About this build

This is a new serverless WebRTC application inspired by the core idea behind PairDrop/ToffeeShare. It does not embed PairDrop code and does not require a PairDrop server. The bundled QR generator is used locally with no network call.

PeerJS is used only to broker the WebRTC handshake. The file data travels over WebRTC, and the Connection diagnostics panel shows the selected ICE path. If PeerJS is unavailable, the existing QR-based direct pairing remains the fallback; TURN credentials can be supplied in Advanced settings for restrictive networks.
